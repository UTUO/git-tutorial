
# Git and GitHub Version Control Practice

This repository is created for a Git and GitHub
version control exercise.

## Project Files
- `index.html`: A simple Hello World webpage.
- `git-logo.png`: Git logo displayed on the webpage.

## Practice
1. Create a local Git repository.
2. Stage and commit a new file.
3. Modify a file and inspect the differences.
4. Add an image and commit the changes.
5. Connect the local repository to GitHub.
6. Push commits to the remote repository.

## Tools
- Git
- Sourcetree
- GitHub
- Antigravity IDE
